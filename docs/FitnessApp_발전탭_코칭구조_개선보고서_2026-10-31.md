## 3. PROPOSED — 코칭 판단 원칙

1. **목표별 성공 기준을 구분한다.** 근력은 비교 가능한 수행 변화, 근비대는 장기 신체 변화와 훈련 수행을 함께 본다. 감량 중 수행 유지도 목표에 맞는 진전으로 해석할 수 있다. 근력·체중 상승만으로 근육 증가를 확정하지 않는다. 목표에 따라 유효한 훈련 변수가 다르다는 근거는 [ACSM 2026](https://pubmed.ncbi.nlm.nih.gov/41843416/)에 있다.
2. **세트 수보다 수행 조건과 반응을 먼저 확인한다.** 종목·기구·중량·반복·본세트 구성, 가능한 경우 RIR(더 할 수 있었던 반복 수)·가동범위·휴식 조건을 함께 본다. 부위별 주간 세트와 빈도를 확인하되 직접 훈련과 보조 기여를 정밀한 단일 점수로 환산하지 않는다. 매번 실패까지 수행하거나 세트를 늘리는 것을 기본 진전으로 취급하지 않는다. [Refalo 등, 2024](https://pubmed.ncbi.nlm.nih.gov/38393985/)는 훈련 경험자 18명의 8주 하체 연구로, 모든 종목의 최적 RIR를 확정하는 근거는 아니다.
3. **정체 판단 전에 이행·피로·결측을 확인한다.** 같은 조건의 수행 하락이 반복되고 낮은 컨디션이 겹치면 훈련 부담 조정 후보로 표시한다. 기록 누락이나 하루 부진만으로 운동량 부족·과훈련을 확정하지 않는다. 자가 회복 기록은 개인 기준선과 비교하는 보조 근거로 사용한다. [Saw 등, 2016](https://pubmed.ncbi.nlm.nih.gov/26423706/)
4. **영양·체중은 추세와 기록 범위를 함께 본다.** 체중은 측정일 수를 표시한 주간 평균으로 비교하고, 가능한 경우 같은 조건의 둘레·체성분 기록을 함께 본다. 식사 기록 누락을 섭취 부족으로 해석하지 않는다. 주간 평균과 개인 반응에 따른 조정은 보디빌딩 비시즌 문헌고찰의 방향과 부합한다. [Iraki 등, 2019](https://pmc.ncbi.nlm.nih.gov/articles/PMC6680710/)
5. **한 번에 주요 변수 하나를 조정하고 다시 평가한다.** 조정 이유·기대 변화·재평가 시점을 남긴다. 주간 점검은 실행과 초기 반응을 보는 제품 주기이며 근비대 판정 기간이 아니다. 전후 차이는 관찰 결과로 표시하고 조정의 인과 효과로 단정하지 않는다.

위 원칙은 연구를 제품에 적용한 설계 제안이다. 통증과 비교 불가·미기록을 다루는 기존 제한을 유지하며, 연구의 집단 평균을 개인의 자동 처방선으로 사용하지 않는다.

## 4. 구현 순서와 완료 기준

| 순서 | 최소 구현 범위 | 완료 기준 |
|---|---|---|
| **P0: 조정과 재평가 연결** | 관심 운동 1개에서 기존 세트 제안의 채택·보류, 적용 세션, 다음 점검을 연결. 현재 목표도 함께 표시 | 실제 완료 기록으로 변경 전후 수행·컨디션과 결측을 보여주고, 유지·되돌림·관찰을 선택할 수 있음 |
| **P1: 목표별 판단 확장** | 목표를 판단 입력에 연결. 주간 부위별 훈련량·빈도, 여러 회차 수행, 신체·회복 추세를 조합 | 같은 기록도 목표에 따라 설명이 달라지고, 근거 부족 시 판단을 보류함 |
| **P2: 연구 설명과 RAG** | 검토된 연구 자료에서 관련 문단 검색, 단일 LLM으로 기록·연구·한계를 연결해 설명 | 대표 질문 10개로 수치 일치·인용 적합성·판단 보류·응답 시간·비용을 평가한 뒤 확장 |

P0의 최소 저장 정보는 계정 범위, 제안 ID·규칙 버전, 근거 기록·기간, 변경 전후 값, 사용자 선택, 적용 세션 ID, 재평가일이다. 기존 로컬 조회·계산·새 세션 생성 경로를 활용하고, 발전 기능이 조정 이력을 소유한다. ‘되돌림’은 다음 운동에서 이전 구성을 선택하는 뜻이며 과거 기록을 수정하지 않는다. 루틴 원본 변경과 자동 처방은 별도 작업으로 분리한다.

검증 시에는 **채택했지만 운동 미완료**, **세트 수 변경으로 직접 비교 불가**, **근거 기록 수정·삭제**, **계정 전환**을 포함한다. 적용한 세션과 이후 비교 가능한 세션을 연결할 수 없으면 효과를 판정하지 않는다. 첫 성공 기준은 답변 수가 아니라 **조정 한 건의 실행과 재평가를 끝까지 추적하는 것**이다.

## 5. RAG와 멀티 LLM의 위치

앱의 계산 코드가 기록 집계·결측·비교 가능성·사용자 선택 이력을 소유하고, RAG는 관련 연구를 찾아 설명을 보강한다. 답변은 **기록에서 확인한 사실 → 가능한 해석 → 선택 가능한 행동 → 출처·한계** 순서로 구성한다. 논문의 대상자·훈련 경험·연구 기간·평가 지표·발행일을 보존하고, 해당 문단이 실제 주장을 지지하는지 확인한다.

외부 모델을 쓰는 경우 사용자 동의 범위의 최소 기록 요약만 전달한다. 네트워크 실패 시에도 로컬 보고서와 기록 흐름은 동작해야 한다. 멀티 LLM은 단일 모델 평가에서 확인된 오류를 줄이는 경우에만 추가한다. 모델 간 합의 자체를 연구 근거로 표시하지 않는다.

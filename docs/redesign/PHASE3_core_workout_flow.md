# Fitness App UI Redesign — PHASE 3. 핵심 운동 흐름

- 문서 상태: 작업 전 명세 / 고정 아님
- 기준 저장소: `Yeon-sik/Yeonsik-Fitness-App`
- 작성 시점 기준 main HEAD: `3795b01653857647832927b78f504a36b620cf8e`
- 실행 원칙: 각 Phase 시작 직전 반드시 최신 `main`을 다시 확인하고, 완료 후 코드 리뷰 결과에 따라 이후 Phase 명세를 수정할 수 있음
- 우선순위: 정확성 > 데이터 무결성 > 단순한 구조 > 유지보수성 > 개발 속도 > 미래 확장성
- 디자인 방향: 화이트/다크 테마 유지, 핵심 강조색은 Pastel Blue
- 언어 원칙: 운동명·식품명·브랜드명·제품명 등 고유명사는 원문 유지. 그 외 교체 가능한 UI 문구는 한국어로 통일. 하단 내비게이션 버튼의 라벨/구조는 별도 승인 없이 변경하지 않음.
- 금지: UI 작업을 이유로 DB schema, migration, 동기화 계약, PriceTrace/OCR 연계 계약을 임의 변경하지 않음


## 목표

상업용 Fitness App의 핵심 루프인
`홈 → 피트니스 → 루틴/자유운동 → 운동 세션 → 종목 선택 → 완료`
를 가장 빠르고 읽기 쉽게 만든다.

이 Phase의 시각 설계는 고정안이 아니다.
실제 적용 후 정보 밀도와 조작성을 실기기에서 검증하고 필요하면 구조를 재조정한다.

## 선행 조건

- PHASE 1, 2 완료 및 리뷰
- 최신 main 재확인
- 기존 workout/session/repository 계약 유지

## 작업 범위

1. 홈
   - Hero의 glow/hologram 제거
   - 오늘의 운동 상태, 현재 세션, 핵심 CTA가 1차 정보
   - 최근 기록/부가정보는 2차 정보
   - tonal Pastel Blue Hero는 허용
   - 영어 장식 문구는 한국어화
   - 고유 운동명은 원문 유지

2. 피트니스 Hub
   - 근력/유산소/식단/영양제/신체기록의 기능 경계는 유지
   - 카드 전체를 가벼운 navigation tile로 단순화
   - 진행 중 운동은 tonal status container로 최상단 표시
   - 각 tile의 정보량은 `아이콘/제목/한 줄 상태` 수준을 기본안으로 함

3. 루틴 목록
   - 카드 안의 중복 CTA 제거 검토
   - 카드 전체 tap을 primary navigation으로 사용
   - 루틴명 / 종목 수 / 최근 수행 등 핵심 메타만 노출
   - 수정/복제/삭제는 secondary menu로 분리

4. 루틴 상세
   - 0종목 루틴에서는 `운동 시작`보다 `종목 추가`가 primary가 되도록 상태 기반 CTA 검토
   - 종목 존재 시에만 시작 CTA 활성화
   - preview는 실제 세션 화면보다 단순화

5. 운동 세션
   - 우선순위:
     1) 현재 운동
     2) 현재 세트
     3) 이전 수행값
     4) 휴식
     5) 전체 진행률
     6) 과거 통계
   - 현재보다 과거 볼륨 차트가 상단을 지배하지 않게 조정
   - 한 손 조작 기준으로 주요 CTA/세트 조작 배치
   - 숫자 정보는 스캔 가능한 정렬 사용

6. 최근 볼륨 차트
   - 현재 세션 0kg을 완료된 과거 기록처럼 연결하지 않음
   - 첫 완료 세트 전에는 current point 숨김 또는 `진행 중`으로 별도 처리
   - 저장된 사실과 현재 계산중 값을 시각적으로 구분

7. 운동 종목 선택
   - 앞/뒤 인체 이미지 기반 선택 구조 유지
   - 선택 근육의 기본 강조색을 Pastel Blue 계열로 변경
   - red/orange는 위험/경고 semantic color로 남김
   - 검색 / 부위 / 세부 부위 / 장비 / 정렬의 우선순위를 실제 사용성 기준으로 재검토
   - 필터 UI는 현재 full-width pill 유지 여부를 실기기 적용 후 결정

## 반드시 유지

- 운동 데이터 저장 구조
- 루틴과 실제 기록의 데이터 분리
- 운동 이미지 자산과 exercise master 연결
- 세션 종료/저장 동작
- 기존 기록과 sync의 의미

## 비범위

- 영양/외식 입력폼
- 기록 달력 전체 개편
- Commercial 설정 분리

## 완료 조건

- 사용자가 홈에서 운동 시작/이어가기를 즉시 찾을 수 있음
- 진행 중 세션에서 현재 운동/세트가 화면의 중심이 됨
- 아직 수행하지 않은 0kg current session이 과거 추세를 오염시키지 않음
- 종목 선택 화면의 filter state가 명확함
- 0종목 루틴에서 잘못된 primary CTA가 노출되지 않음
- 고유명사를 제외한 영어 장식/상태 문구가 가능한 범위에서 한국어화됨

## 코드 리뷰 체크포인트

- UI 편의를 위해 repository의 사실값을 바꾸지 않았는가
- current/in-progress 데이터를 persisted history와 혼합하지 않았는가
- 세션 상태가 화면 재렌더링/회전/복귀 시 손실되지 않는가
- 운동 추가 검색 성능 개선 등 기존 최근 기능이 회귀하지 않는가
- UI state와 DB state의 경계를 지켰는가

## Phase 종료 후 결정

실제 운동 1회 이상 실기기 테스트 후:
- 카드 밀도
- 세트 행 높이
- 필터 형태
- Pastel Blue 사용량
- CTA 크기

를 재조정할 수 있다.
리뷰 결과는 PHASE 4의 form density에도 반영한다.
